# Security

## Reporting a vulnerability

Report it privately, through GitHub's
[private vulnerability reporting](https://github.com/SingulaTeam/rust-sdk/security/advisories/new)
for this repository. Please do not open a public issue, pull request or
discussion about it.

Include what you can of:

- what an attacker can do, and what they need to do it;
- the steps or code that show it;
- the version or commit you tested.

We will acknowledge the report, keep you informed while we work on it, and
credit you when the fix is published, unless you would rather not be named.
Please give us a reasonable time to fix it before you disclose it.

## Scope

This repository: the client SDK, its wire formats and its bundled artifacts.
A weakness in the protocol itself — the Control Plane, the nodes, the
contracts — is just as welcome here; we will take it to the right place.

## Supported versions

Fixes go into the latest release.
